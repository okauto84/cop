# [CoP] 지능형 특허 분석 및 검색식 자동 생성 시스템 (SearchMath)
---

## 1. 개요 (Overview)
방대한 특허 및 출원 문서의 핵심 내용을 신속하게 파악하고, 유사 특허 조사를 위한 최적의 검색식을 도출하기 위해 **Streamlit**과 **OpenAI GPT-5** 기반의 지능형 분석 시스템을 구축합니다. 사용자가 PDF 문서를 업로드하면 AI 특허 심사관의 관점에서 기술적 요지를 분석하고 표준 검색 문법에 맞는 검색식을 생성합니다.

---

## 2. 주요 분석 및 검색 항목 (Metadata)
정밀한 특허 분석을 위해 아래 3가지 핵심 영역을 중심으로 데이터를 처리하고 검색식을 구조화합니다.

| 항목 | 상세 설명 |
| :--- | :--- |
| **발명의 효과** | 해당 발명이 달성하는 핵심적인 기술적 이점 및 성과 (약 200자) |
| **청구항 요지** | 독립 청구항을 중심으로 한 핵심 기술 구성 및 권리 범위의 핵심 요약 |
| **특허 검색식** | 논리연산자(AND, OR, NEAR 등)를 활용한 표준 특허 검색 문법 조합 |

---

## 3. 시스템 워크플로우 (Workflow)
문서 업로드부터 검색식 최적화까지 이어지는 4단계 자동화 프로세스입니다.

1. **PDF 데이터 추출 (Parsing)**: `pypdf`를 활용하여 업로드된 특허 문서의 텍스트 데이터를 레이아웃에 맞춰 추출
2. **핵심 기술 분석 (Analysis)**: `gpt-5-mini` 모델이 발명의 효과와 청구항 중심의 기술 요지를 요약 및 생성
3. **검색식 자동 생성 (Query Generation)**: 분석된 기술 키워드에 특허청 표준 연산자(NEAR, NOT 등)를 적용하여 실행 가능한 검색식 도출
4. **사용자 편집 및 확정 (Review)**: 생성된 검색식을 인터랙티브 텍스트 에디터에서 직접 수정하고 검토

---

## 4. 핵심 기술 요소
본 시스템의 신뢰도 높은 분석을 위해 다음의 전문 기술 사양을 적용합니다.

> ### 💡 지능형 특허 심사 프롬프트
> 베테랑 특허 심사관의 페르소나를 LLM에 부여하여, 단순 요약을 넘어 특허 검색에 실질적으로 활용 가능한 기술 키워드와 동의어를 식별합니다.
> 
> ### 🔍 표준 검색 연산 로직 (Search Syntax)
> 구문 검색(" "), 논리연산(*, +, !), 거리 연산(^), 와일드카드(?) 등 특허 전문 검색 엔진의 표준 문법을 엄격히 준수하여 검색식을 생성합니다.

---

## 5. 기대 효과
* **분석 시간 단축**: 수십 페이지의 특허 문서를 일일이 읽지 않고도 핵심 기술 구성과 효과를 즉각 파악 가능
* **검색 정확도 향상**: NEAR(^) 연산자 등을 활용하여 단어 간 거리를 고려한 정밀한 유사 특허 검색 지원
* **업무 표준화**: 개별 연구자마다 다른 검색식 작성 방식을 표준화된 문법으로 통일하여 검색 결과의 일관성 확보
