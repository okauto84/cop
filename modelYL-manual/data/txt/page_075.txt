시동
도어를 열고 Model Y에 승차하면 터치스크린이 켜지고 모든 제어 장
치를 작동할 수 있습니다. Model Y을(를) 변속하려면 브레이크 페달
을 밟고 터치스크린의 주행 모드 스트립에서 위로 살짝 밀어 ‘D’ 또는 
아래로 살짝 밀어 ‘R’을 선택합니다(변속 페이지의 80 참조).
자동 출차 변속을 활성화하면, Model Y이(가) 감지된 주변 환경에 따
라 주행(D) 또는 후진(R)을 선택합니다. 브레이크 페달을 밟으면 터치
스크린의 주행 모드 스트립에 표시된 선택된 주행 모드로 차량이 변
속되고(운전석 도어가 닫혀 있고 운전석 안전벨트를 체결한 경우) 가
속 페달을 밟으면 차량이 해당 방향으로 이동합니다.
참고: 자동 출차 변속을 켜거나 끄려면 컨트롤 > 주행 설정 > 자동 출
차 변속을 터치합니다.
자동 변속이 활성화된 상태에서 가속하기 전에, 터치스크린을 확인하
여 Model Y이(가) 사용자가 의도하는 주행 모드(D 또는 R)로 변속되
었는지 확인합니다. 선택이 올바르지 않거나 자동 출차 변속이 활성
화되지 않은 경우 터치스크린의 주행 모드 스트립에서 위로 살짝 밀
어 ‘D’ 또는 아래로 살짝 밀어 ‘R’로 새 주행 모드를 선택합니다. 참조 
항목: 변속 페이지의 80.
참고: 주행용 비밀번호가 활성화된 경우(주행용 비밀번호 페이지의 
135 참조), Model Y을(를) 운전하기 전에 터치스크린에 유효한 PIN
을 입력해야 합니다.
Model Y을(를) 운전할 때 알아야 할 모든 사항이 터치스크린에 표시
됩니다.
주행 불가능 - 인증 필요
브레이크를 밟았을 때 Model Y에서 키를 감지하지 못하면 (핸드폰 
키가 감지되지 않았거나 키 카드를 사용한 후 2분이 경과한 경우) 터
치스크린에 주행하려면 인증이 필요하다는 메시지가 표시됩니다.
이 메시지가 표시되면 RFID 송신기가 키 카드를 읽을 수 있는 스마트
폰 도크에 키 카드를 두십시오. 2분 인증 유효 시간이 시작되며, 브레
이크 페달을 밟아서 Model Y 차량의 시동을 걸 수 있습니다.
Model Y에서 핸드폰 키를 감지하는 데 여러 요인이 영향을 미칠 수 
있습니다(예: 장치의 배터리가 부족하거나 장치가 꺼져 Bluetooth를 
사용하여 더 이상 통신할 수 없는 경우).
항상 핸드폰 키 또는 키 카드를 소지하십시오. 주행 후, Model Y을
(를) 다시 시동하려면 키가 필요합니다. 반드시 키를 지니고 하차해야 
Model Y을(를) 자동 또는 수동으로 잠글 수 있습니다.
전원 끄기
주행을 마치고 주차(P)로 변속하면 그냥 차량에서 내릴 수 있습니다.
핸드폰 키 및 리모트키를 가지고 Model Y에서 내리면 자동으로 전원
이 꺼지고 터치스크린이 꺼지며 차량 전원이 자동으로 종료됩니다.
Model Y 또한 기어가 ‘P’로 설정된 지 30분이 지나면 운전석에 앉아 
있어도 자동으로 전원이 꺼집니다.
일반적으로 필요한 경우는 아니지만, 차량이 움직이지 않을 때는 운
전석에 앉아 있는 상태로 Model Y의 전원을 끌 수 있습니다. 컨트롤 
> 안전 > 전원 끄기를 터치합니다. Model Y 브레이크 페달을 밟거나 
운전석 도어를 열면, 잠시 후 차량 전원이 자동으로 다시 활성화됩니
다. 필요한 경우 차량에서 내렸다가 다시 탑승하세요.
참고: Model Y 은(는) 운전자가 하차 중이라고 판단할 때마다 자동으
로 P로 변속합니다(예: 운전석의 안전벨트가 풀려 있고 차량이 거의 
정지 상태인 경우). ‘N’으로 변속하는 경우 하차하기 위해 도어를 열
면 차량이 ‘P’로 변속됩니다. 차량을 'N' 상태로 두려면 견인 모드을
(를) 활성화해야 합니다(차량 운송 기사 지침 페이지의 210 참조).
차량 전원 끄고 켜기
Model Y이(가) 이상 동작을 보이거나 설명이 없는 경고가 표시되는 
경우 전원을 끈 다음 켤 수 있습니다.
참고: 터치스크린이 반응하지 않거나 일반적이지 않은 동작을 보이는 
경우, 차량의 전원을 껐다가 켜기 전에 재부팅하세요.(터치스크린 다
시 시작하기 페이지의 9 참조).
1. 기어를 P(주차)로 전환합니다.
2. 터치스크린에서 컨트롤 > 안전 > 전원 끄기를 터치합니다.
3. 차량을 조작하지 말고 2분 이상 대기합니다. 도어를 열거나 브레
이크 페달을 밟거나 터치스크린을 터치 등의 조작을 하지 마십시
오.
4. 2분 후 브레이크 페달을 밟거나 도어를 열어 절전 모드를 해제합
니다.
