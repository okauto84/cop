# [CoP] KIPI 메신저 쪽지 검색 기능 개선 (RAG 기반 파일럿)

---

## 1. 개요 (Overview)
기존 KIPI 메신저의 쪽지 검색 기능을 보완하기 위해, **RAG(Retrieval-Augmented Generation)** 아키텍처를 도입하여 자연어 기반의 정밀 검색 시스템을 구축합니다.

---

## 2. 주요 검색 메타데이터
단순 키워드 검색을 넘어, 아래 4가지 핵심 필드를 기반으로 데이터 벡터화 및 인덱싱을 진행합니다.

| 필드명 | 상세 설명 |
| :--- | :--- |
| **발신일자** | 쪽지가 전송된 구체적인 시점 |
| **발신인** | 메시지를 보낸 사용자 정보 |
| **수신인** | 메시지를 받은 사용자 정보 |
| **내용** | 쪽지 본문 전체 텍스트 (핵심 검색 대상) |

---

## 3. 파일럿 시스템 워크플로우 (Workflow)
사용자가 직접 데이터를 제공하고 LLM과 대화하며 정보를 찾는 5단계 프로세스입니다.

1. **데이터 추출 (Export)**: 메신저 내 쪽지 이력을 로컬 파일로 다운로드
2. **데이터 업로드 (Upload)**: 파일럿 시스템 인터페이스를 통해 파일 로드
3. **자연어 질문 (Query)**: 사용자가 대화창에 질문 입력
4. **유사도 검색 (Retrieval)**: **TF-IDF 알고리즘**을 사용하여 질문과 관련성 높은 쪽지 탐색
5. **답변 생성 (Generation)**: LLM이 검색된 쪽지 내용을 분석하여 최종 답변 제공



---

## 4. 핵심 기술 요소
본 파일럿 시스템의 효율적인 구현을 위해 다음 기술을 활용합니다.

> ### 💡 RAG (검색 증강 생성)
> LLM이 학습하지 않은 최신/내부 데이터(쪽지)를 외부 저장소에서 찾아와 답변의 근거로 활용하는 기술입니다. 
> 
> ### 🔍 TF-IDF (검색 알고리즘)
> 파일럿 단계의 신속한 검증을 위해 도입된 통계적 수치입니다. 특정 단어가 문서 내에서 얼마나 중요한지를 계산하여, 질문에 딱 맞는 쪽지를 빠르게 필터링합니다.

---

## 5. 기대 효과
* **검색 정확도 향상**: 인물, 날짜, 문맥이 결합된 복합 질문 처리 가능
* **업무 연속성 보장**: 과거 히스토리를 빠르게 조회하여 업무 누수 방지
* **시스템 고도화**: 향후 벡터 DB 도입 및 Semantic 검색으로의 확장성 확보
