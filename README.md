## 1. 카테고리별 통계
| 카테고리 | 빈도수 | 주요 내용 |
| :--- | :---: | :--- |
| **검색 품질** | 24건 | 구성요소 추출 정확도, 유사도 순위, 키워드 매칭 관련 |
| **기능 추가** | 24건 | 도면 조회, 날짜 필터링, 하이라이트 기능 요청 |
| **속도** | 2건 | 검색 처리 속도 및 시스템 대기 시간 |
| **오류** | 1건 | 서버 에러(Internal Server Error) 발생 보고 |

---

### 장점 (Advantages) & 강점 (Strengths)
* **자동 추출 기능:** 출원번호 입력 시 청구항 구성요소를 자동으로 추출하여 업무 편의성 제공.
* **유사도 랭킹:** 문장 기반 검색 시 1~2순위에 유사 특허가 도출되는 등 검색 품질이 우수함.
* **프로세스 지원:** '발명 분석 → 구성요소 분석 → 검색'으로 이어지는 심사 워크플로우를 효과적으로 보조.

### 단점 (Disadvantages) & 약점 (Weaknesses)
* **시각 자료 부재:** 검색 결과 리스트에서 도면을 즉시 확인할 수 없어 기계/장치 분야 심사에 제약.
* **메타데이터 부족:** 공개/등록일자 정보가 미비하여 인용발명 적격성 판단에 추가 시간 소요.
* **필터링 미흡:** 날짜 제한 검색이나 결과 내 재검색 등 세부 필터링 기능 부족.
* **분야별 편차:** 바이오/화학 분야의 서열번호나 특정 키워드에 대한 가중치 처리 보완 필요.

---

## 3. 향후 개선 로드맵
1. **[UI/UX]** 검색 결과 내 도면 일괄 조회 및 주요 메타데이터(날짜) 표시 기능 추가.
2. **[검색 엔진]** 특허요건 판단 기준일 설정 및 날짜 기반 필터링 기능 구현.
3. **[AI 고도화]** 사용자 프롬프트 입력을 통한 검색 의도 반영 및 중요 키워드 가중치 조정 기능 도입.
